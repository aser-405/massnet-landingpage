# ماس نت — HTML وJavaScript مع إرسال مباشر لتليجرام

هذه النسخة مستقلة: HTML + Tailwind CSS محلي + CSS مخصص + JavaScript عادي. لا تحتاج React أو PHP أو Cloud Functions أو قاعدة بيانات أو عملية build.

شاشة التحميل بالشعار واسم ماس نت ما زالت موجودة. الفورم يرسل الاسم والهاتف والعنوان والباقة والملاحظات مباشرة من المتصفح إلى Telegram Bot API باستخدام POST وsendMessage.

## إعداد البوت

ملف `site-config.js` يحتوي التوكن ورقم المحادثة اللذين زوّدتنا بهما. يمكنك تعديلهما فيه. إذا تم تغيير التوكن أو إلغاؤه، ضع التوكن الجديد. افتح البوت من الحساب المستهدف واضغط Start قبل تجربة الإرسال.

وفق اختيارك، التوكن موجود في الواجهة ويمكن لأي زائر قراءته واستخدام صلاحيات البوت. لا يوجد سيرفر لحماية التوكن أو فرض حد للطلبات. إخفاء أو تشفير النص داخل JavaScript لا يجعله سرياً.

## الرفع على Firebase Hosting

فك الضغط، وافتح الطرفية داخل المجلد الذي يحتوي `index.html`، ثم نفّذ:

```bash
npm install -g firebase-tools
firebase login
firebase deploy --project YOUR_FIREBASE_PROJECT_ID --only hosting
```

استبدل معرّف المشروع بمشروعك الفعلي. لا تحتاج npm install للمشروع أو npm run build. أداة Firebase فقط تحتاج Node.js للرفع، أما الموقع نفسه فملفات ثابتة.

لربط الدومين: Firebase Console > Hosting > Add custom domain، ثم طبّق سجلات DNS التي يعرضها Firebase.

## الملفات

- `index.html`: المحتوى والفورم والأسعار.
- `site-config.js`: توكن البوت وchat ID.
- `assets/app.js`: التحقق من الفورم والإرسال المباشر لتليجرام.
- `assets/loader.js`: شاشة التحميل.
- `assets/styles.css`: التنسيق المخصص.
- `assets/tailwind.css`: Tailwind مجهّز للفئات الحالية.
- `firebase.json`: إعداد الاستضافة.

## سلوك الإرسال

لا تظهر رسالة النجاح إلا بعد رجوع `ok: true` من تليجرام. عند الرفض أو خطأ الشبكة تبقى بيانات الفورم. عند انقطاع الاتصال قد تكون الرسالة وصلت دون رجوع التأكيد؛ تحقق من تليجرام قبل إعادة الإرسال. لا توجد إعادة إرسال تلقائية، ولا يتم حفظ الطلبات في Firestore أو إرسالها لملف PHP.

## التحقق

تم فحص JavaScript ومحاكاة الطلبات المباشرة وحالات النجاح والرفض والإعداد الناقص. لم يتم إرسال رسالة فعلية أو اختبار التوكن على الشبكة، ولم يُرفع الموقع إلى حساب Firebase. جرّب طلباً واحداً من الرابط المنشور وتأكد من وصوله. إذا منعت شبكة المستخدم الوصول إلى Telegram أو منعت سياسة المتصفح قراءة الرد، لن يظهر نجاح وهمي؛ ستبقى البيانات مع رسالة خطأ.
